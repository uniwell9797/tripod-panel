## 4. 首次发布（Releases → Draft a new release）

Tag 用 `v1.0.0`，标题和说明可以直接用下面这段：

**标题：**

```text
v1.0.0 · 第一个公开版本
```

**说明：**

```markdown
把本机 ComfyUI 包成一个傻瓜式面板的第一个公开版本。

## 能做什么
- 创作：文生图、图片编辑（多图参考）、编辑工具（换衣 / 换发型 / 换脸 / 老照片修复 / 移除对象 / 局部重绘）
- 多图合成一个镜头：多张照片自动抠图 → 自动排版 → 模型统一光线、去掉拼接痕迹
- 图像工具：扩图、多角度、动作姿态（骨骼编辑器）
- 批量：批量抠图、批量提取服装、批量换装
- 视频：照片动起来、按音频说话、首尾帧生视频、视频后期（拼接 / 字幕 / 水印 / 配乐）
- 音频 / 数字人：配音（可克隆音色）、照片按音频开口说话
- 其它：作品库、历史记录、文件浏览、模型管理、任务队列与实时预览

## 特点
- 全中文、人话报错；档位自动降级、显存不够自动降；ComfyUI 掉线自动拉起
- 单文件后端（panel.py）+ 单文件前端（new_ui.html），没有构建步骤
- 100% 本机推理，不上传任何东西

## 说明
- **本仓库不含任何模型权重**，模型请按 models.md 自行从官方渠道下载，各自遵循各自许可证
- 使用前请阅读 DISCLAIMER.md（免责声明）
- 有问题欢迎提 Issue；也欢迎把 README 里那段"交给 AI Agent 安装"的提示词转给任何 Agent 帮你装
```
